# startrakuyomi.koplugin

A small companion plugin for [Rakuyomi](https://github.com/tachibana-shin/rakuyomi) that gives you the option to automatically open Rakuyomi's manga library view when KOReader starts.

## Requirements

- [KOReader](https://koreader.rocks)
- [Rakuyomi](https://github.com/tachibana-shin/rakuyomi) installed and working

## Installation

1. Download `startrakuyomi.koplugin.zip` from [Releases](../../releases)
2. Unzip it
3. Copy the `startrakuyomi.koplugin` folder into your KOReader plugins directory (`koreader/plugins/`)
4. Restart KOReader

## Usage

Go to **File Browser → Start with → Rakuyomi** to enable. 

When enabled, KOReader will open directly into Rakuyomi's library view on startup.
